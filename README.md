<h2> Motivation: </h2>
<p>
ASE can be detected by quantifying RNA-Seq reads, but this approach requires at least a heterozygous variant to be present in the transcripts. ASE can be aslo detected using sequences from a large number of individuals which imposes more costs. Therefre, here we are using a family approach for idenftifying ASE and possible cis-regulatory elements and avoiding the previous approachs' limitations 
</p>
